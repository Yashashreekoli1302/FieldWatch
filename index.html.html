Field Watch

A smart-farming console for a mixed-crop farm: sensor alerts, offline field nodes, yield chart events, a crop guide and advisory data from a backend service.

1. Field sensor alerts

Readings from soil probes and weather stations are filtered, mapped and reduced into an alert table.

2. Offline field node scanner

A NodeIterator finds every node marked offline and restyles it. A TreeWalker then updates its label.

3. Crop yield chart and event flow

Click a crop bar or its link. Capture listeners run top-down, bubble listeners bottom-up. The link’s default navigation is blocked.
